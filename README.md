 🥑 NutriPredict

Your Intelligent Personal Nutrition & Health Companion

A smart AI-powered nutrition recommendation system that helps you make healthier food choices every day.

 ✨ Features

- Real-time Nutritional Analysis** — Calories, Protein, Carbs, Fat, Fiber & more
- Beautiful & Intuitive UI** — Designed with food and wellness in mind
- Model Retraining Pipeline** — Continuously improves with new data
  
🎯 Project Objectives

- Objective 1**: Data Collection & Ingestion (Completed ✅)
- Objective 2**: Data Pre-processing & Cleaning
- Objective 3**: Personalized Nutrition Recommendations (Completed ✅)
- Objective 4**: Model Deployment & UI Development (In Progress)

 🛠️ Tech Stack

- Backend: Python, Pandas, Scikit-learn
- Model: Random Forest / Machine Learning Pipeline
- Frontend: Streamlit (Beautiful & Interactive UI)
- Version Control: Git & GitHub
- Experiment Tracking: MLflow
- Deployment Ready: Heroku / Render / Streamlit Cloud
